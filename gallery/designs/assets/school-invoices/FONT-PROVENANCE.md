# CJK font

Noto Sans SC by Adobe / Google; SIL Open Font License 1.1 (FONT-LICENSE.txt). Generated 2026-10-28 from the official Google Fonts subset API.

FontTools instantiates static 400/700 weights and renames the modified fonts to Demo School CJK. Static fonts avoid Chromium variable-font Type 3 PDF output. The OFL Reserved Font Name Source is not used for the modified family. No system font installation.

cjk-glyphs.txt contains all requested non-ASCII characters, including Chinese punctuation. Additional custom CJK input requires extending the subset. Latin text uses the existing licensed DejaVu fonts in ../demobank.

Regenerate with scripts/build-school-invoice-fonts.py in a local venv with fonttools and brotli. Normal builds are offline and use the committed subsets.
