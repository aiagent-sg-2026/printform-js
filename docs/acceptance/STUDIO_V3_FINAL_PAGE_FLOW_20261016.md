- 最终 footer 在实际输出宽度及真实页总数下试排；只有放不下才增加页面。回滚试排节点和页码注册，不留下幽灵页码。

## 保留的失败与修正

1. 评审新增复现确认两个产品缺陷：嵌套原子签名没有获得续页预算；keep-next试排遗漏未消费的一次性表头。修复共同几何规则，不特判样张文字。
2. 第一份临时Playwright配置因CJS/ESM默认导出互操作，在启动浏览器前失败。改用独立临时配置；不计产品通过项。
3. 首次完整42项浏览器运行39通过、3失败：新增静态HTML业务行被测试助手错误当成0条绑定数据并要求repeat身份。助手现在从**输入原行**取逻辑行总数，只对实际重复绑定行核对repeat；文字、顺序、金额、签名、几何与页数断言保持。随后完整42项通过。
4. JSDOM未实现confirm/伪元素样式、Node模块类型提示及SDK浏览器外部化警告保留，不静默屏蔽。
